# 📊 Data Professional Survey Breakdown - Power BI Dashboard

A fully interactive Power BI dashboard analyzing survey data from 630 data professionals worldwide. 
Built as a hands-on tutorial project following Alex the Analyst's YouTube course.

[image alt] () 

## 🎯 Project Overview
This dashboard explores trends in the data industry: salaries, job roles, programming languages, 
work/life balance, and difficulty breaking into the field.

**Dataset**: Survey of 630 Data Professionals 
**Tool**: Microsoft Power BI Desktop 
**Skills Used**: Data Cleaning, DAX, Data Visualization, Storytelling, Business Insights

## 📈 Key Visuals & Insights

### 1. **Demographics**
- **Country Breakdown**: Survey takers from Canada, UK, US, India, and Other
- **Count of Respondents**: 630 total

### 2. **Career & Compensation**
- **Average Salary by Job Title**: 
    - Data Scientist has the highest average salary
    - Data Engineer and Data Architect follow
- **Happiness With Salary**: Average rating of 4.27 / 10
- **Happiness With Work/Life Balance**: Average rating of 5.74 / 10

### 3. **Skills & Entry**
- **Favorite Programming Language**: Python is the most popular by far
- **Difficulty to Break into Data**: 
    - 42.7% said "Neither easy nor difficult"
    - 24.76% said "Difficult"
    - Only 6.98% said "Very Easy"

## 🛠️ Tools & Techniques Used
- **Power Query**: Data cleaning and transformation
- **DAX**: Calculated measures for Average Salary, Happiness Scores
- **Visuals**: Bar charts, Donut charts, Treemap, Gauge charts, Stacked columns
- **Design**: Clean layout with focus on storytelling

## 🚀 How to View This Dashboard
1. Download the `Final Power BI Project.pbix` file from this repo
2. Open with Microsoft Power BI Desktop
3. Click "Refresh" to interact with all filters
